# ゲームバックログ管理アプリ

積みゲー・プレイ中・クリア済みのゲームを記録するためのWebアプリ。
Flask + SQLite製。個人用のシンプルなMVPから始まり、認証・RAWG連携・ちょっとしたSNS機能まで持つ形に育っています。

## 機能

- **ゲーム管理**: タイトル・ステータス(積みゲー/プレイ中/クリア済み)・評価(1〜5)・メモ・お気に入りマーク
- **検索・並び替え**: タイトル検索、更新日/登録日/評価/タイトル/プレイ時間での並び替え、お気に入り絞り込み
- **RAWG API連携**: タイトル入力時に候補とカバー画像を自動取得(`RAWG_API_KEY`未設定でも他の機能は問題なく動作)
- **プレイ時間記録**: ゲームごとに日付・時間を記録し、合計プレイ時間を表示
- **マルチユーザー対応**: アカウント登録・ログイン。各ユーザーのデータは完全に分離
- **共有リンク**: ログイン不要で閲覧できる読み取り専用URL(メモは非公開)を発行・再発行・停止できる
- **公開プロフィール**: ユーザー名ベースの公開プロフィール(`/users/<username>`)。オン/オフ切り替え可能
- **ソーシャル機能**: フォロー、アクティビティフィード(ゲーム追加・クリア・評価)、いいね、コメント
- **通知**: フォロー・いいね・コメントを通知。ヘッダーに未読バッジ表示
- **ブロック**: ブロックすると相互フォロー解除、プロフィール・フィード・ユーザー一覧から相互に非表示に
- **アイコン設定**: 画像URLを直接指定、またはお気に入りゲームのカバー画像から選択

## 必要なもの

- Python 3.9以上

## セットアップ

```bash
# 1. このフォルダに移動
cd game-backlog-app

# 2. (推奨) 仮想環境を作る
python -m venv venv
source venv/bin/activate      # Windowsの場合: venv\Scripts\activate

# 3. 依存パッケージをインストール
pip install -r requirements.txt

# 開発用(テストも実行したい場合はこちら)
pip install -r requirements-dev.txt
```

### 環境変数(`.env`)

プロジェクト直下に `.env` ファイルを作成する(`.gitignore`済みなのでコミットされない)。

```
# 省略可: 設定するとタイトル自動補完・カバー画像取得が有効になる
# https://rawg.io/apidocs で無料アカウント登録して取得
RAWG_API_KEY=your-rawg-api-key

# 省略可: 設定しない場合は開発用の固定キーが使われる(個人利用ならそれで十分)
# セッションの署名に使うランダムな文字列。生成例: python -c "import secrets; print(secrets.token_hex(32))"
SECRET_KEY=your-random-secret-key
```

### データベースの初期化

初回のみ実行する(`games.db` が作られる)。2回目以降は不要(アプリ起動時に必要なテーブル・列は自動的に追加される)。

```bash
flask --app app init-db
```

`flask`コマンドがPATHに見つからない場合は `python -m flask --app app init-db` を使う。

## 起動

```bash
flask --app app run --debug
```

起動したら http://127.0.0.1:5000 をブラウザで開く。初回は「新規登録」からアカウントを作成する。

## テスト

```bash
pip install -r requirements-dev.txt
pytest
```

テストは一時ファイルに作った専用のDBを使うため、`games.db`(実データ)には一切触れない。

## データベースについて

- 通常のアプリ起動では、新しいテーブルや列が必要になった場合は自動的に(既存データを壊さずに)追加される
- `flask init-db` は既存データを**全て消して**スキーマを作り直すコマンド。データを保持したまま最新化したいだけなら、`flask init-db` は実行せず普通に起動すればよい
- `games.db` は `.gitignore` 対象。個人のプレイ記録なのでコミットされない

## 注意

- `SECRET_KEY` を設定せずに起動すると開発用の固定キーが使われる。個人利用のローカル環境なら問題ないが、他人からアクセスされうる環境で動かす場合は必ず `.env` で独自のキーを設定すること
- ユーザー登録は誰でも自由にできる(招待制ではない)。家族・友人など少人数での利用を想定した設計
